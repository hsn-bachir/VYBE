### Finding and practical conclusion

This establishes **date-dependent reproduction on origin/dev**, rather than assuming the old failure is unrelated. Read-only source inspection supports a fixture/rotation interaction: the service selects a loved reference by UTC day-of-year modulo the number of loved references, while this fixture's candidates always advertise only `similar:1` and `similar:3`. The rated loved references include IDs 1 and 2; November 26 selects the unsupported ID 2, whereas November 27 selects ID 1. The resulting empty similar section is omitted by the service. The same tracked code and frozen-clock behavior occur on both branches.

This is diagnostic evidence for the recommendation owner to review, not authorization to change recommendation behavior or its fixture. The date-sensitive regression remains open even though the current-date suite is green. Missing-environment warnings are a separate isolated-harness limitation, not the six-versus-five assertion cause.
